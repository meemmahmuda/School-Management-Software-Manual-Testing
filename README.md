# RK-EMS — Manual Testing & UAT Tracking

Manual QA / UAT (User Acceptance Testing) documentation for **RK-EMS (Education Management System)**, covering both the **Back Office (RKAdmin)** portal and the **Institute Portal (RKEMS)**. This repository tracks reported issues, feature requirements, training progress, and module-wise completion status gathered during hands-on testing of the system.

## 🛠️ Issue Log Format

Each entry in **Error and Requirment** includes:
- **Module** & **Feature**
- **Problem / Question** description
- **Note** (dev clarification)
- **Portal Type** (Back Office / Institute Portal)
- **Date and Time** reported / replied
- **Reply From Dev Team**
- **Final Status** (Completed / Pending / Open / Check Note)
